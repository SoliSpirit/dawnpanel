# DawnPanel brand

Original vector logo designed for DawnPanel. `dawn-mark.svg` is the responsive mark used in site headers, footer, favicon and support chat. `dawn-lockup.svg` is the downloadable wordmark for light backgrounds. Website Persian typography remains live HTML for clear rendering and accessibility.

Palette: teal #087e8b, bright teal #19b8b2, charcoal #152630, neutral day #f5f6f8. Night mode: background #10171e, surface #17232c, accent #4bc5ce.

The reference screenshots guided the layout and spacing; no source-template code, logos, prices, ratings or promotional claims were copied.
